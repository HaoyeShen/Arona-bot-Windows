ARONA 是一个运行在 Windows 桌面的微信自动回复机器人。 默认人格是《蔚蓝档案》的 阿洛娜，也可以切换到 普拉娜，或创建属于你的新人格。

支持本地 Ollama、DeepSeek / OpenAI 兼容 API、训练资料检索、图片理解、 表情包、群聊概率回复和管理员指令。所有聊天数据都保存在本机。

CORE FEATURES

她不只是自动回复。

从模型选择、人格、训练资料到群聊规则，所有东西都可以在桌面端调整。

01 / PERSONA

双人格自由切换

阿洛娜与普拉娜内置人格，可在私聊或不同群聊中分别使用，也支持编辑和新增。

02 / MODEL

本地与 API 皆可

Ollama 本地模型、DeepSeek 及 OpenAI 兼容接口。无需把聊天记录交给不信任的服务。

03 / MEMORY

训练资料检索

上传 txt、md、pdf、docx 等资料，建立本地知识库；回复前理解消息并检索相关片段。

04 / VISION

读懂对方图片

从微信本地缓存解密图片，交给视觉模型生成描述，再进入正常回复上下文；Token 计入统计。

05 / STICKER

会发表情包

根据情绪与语境从本地表情库选择，支持自定义表情包；不会为了用而用。

06 / GROUP

群聊规则可控

每个群独立回复概率；被 @ 时必回；可设置只认 @阿洛娜 / @ARONA，避免对群聊刷屏。

07 / ADMIN

管理员指令

密码 + 管理员名单双重限制，支持重置上下文、调试、暂停回复和自动恢复。

08 / CONTEXT

长上下文摘要

超过阈值后自动把旧对话压缩成摘要，只把摘要和最近消息交给模型，控制成本与延迟。

INTERFACE / BLUE ARCHIVE STYLE

蓝白、青色与粉色。

不是命令行黑框，也不是普通后台。这是一个真正像“什亭之匣”的桌面界面。

QUICK START

四步开始。

无需编译、无需配置复杂服务。下载源码，安装依赖，启动程序，然后添加你想监听的微信会话。

Windows 10 / 11 Python 3.12 微信 4.1.15 Ollama 可选
01

下载项目

从 GitHub Release 下载最新源码压缩包。

02

安装依赖

双击项目目录中的「安装依赖.bat」，等待虚拟环境初始化完成。

安装依赖.bat
03

启动 ARONA

双击「启动 ARONA.bat」，程序会自动检查微信连接并打开桌面界面。

启动 ARONA.bat
04

添加监听对象

在「监听对象」添加好友或群聊，选择人格和回复概率，点击启动机器人。

监听对象 → 添加 → 启动机器人
ADMIN COMMANDS

只属于你的控制台。

管理员模式需要密码 + 管理员名单双重验证；只有通过验证的发送者可以下指令。

/admin请求管理员密码，验证成功后进入管理员模式
/reset清空当前会话的上下文记忆
/test直接发送一条调试信息，不调用模型或 API
/off暂停当前会话智能回复一小时，一小时后自动恢复
/start恢复当前会话智能回复
/end询问是否保存修改，使用 /yes 或 /no 退出
安全提示：首次使用请到「设置 → 管理员指令」修改默认密码，并把你的微信昵称或 wxid 加入管理员名单。 管理员模式会暂停所有会话的智能回复与模型调用。
